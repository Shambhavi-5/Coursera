# Simple Interest Calculator

## Description

This project is a simple interest calculator written in Python. It calculates the simple interest based on the principal amount, rate of interest, and time period provided by the user.

## Formula

The formula used to calculate Simple Interest is:

**Simple Interest = (P × R × T) / 100**

Where:

* **P** = Principal amount
* **R** = Rate of interest
* **T** = Time in years

## Example

Suppose:

* Principal (P) = ₹10,000
* Rate of Interest (R) = 5%
* Time (T) = 2 years

Then:

**Simple Interest = (10,000 × 5 × 2) / 100**

**Simple Interest = ₹1,000**

## How to Run

1. Make sure Python is installed on your computer.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run the following command:

```bash
python simple_interest.py
```

5. Enter the principal amount, rate of interest, and time when prompted.
6. The calculator will display the calculated simple interest.
